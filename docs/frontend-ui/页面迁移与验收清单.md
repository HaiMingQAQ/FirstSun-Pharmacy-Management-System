# 页面迁移与验收清单

## 开发前

- [ ] 已确认自己负责的模块与文件范围。
- [ ] 已同步包含公共 UI 基座的最新 `main`。
- [ ] 已阅读 UI 风格规范和前端界面统一规范。
- [ ] 已选择药品分类页或药品档案页作为页面模板。
- [ ] 已记录原页面 API、权限标识、字典、校验和关键业务流程。

## 实现要求

- [ ] 使用公共设计令牌，不在页面散落品牌色、圆角和阴影常量。
- [ ] 使用公共 Pharmacy 组件，不重复实现页面标题、指标条和详情面板。
- [ ] 菜单和按钮使用统一 SVG/Iconify 图标，不使用单字或 Emoji 充当图标。
- [ ] 高频查询条件默认展示，低频条件进入“更多筛选”。
- [ ] 简单表单使用 Dialog，复杂表单使用 Drawer 和连续分区。
- [ ] 父子数据使用真实树形层级、缩进和展开控件，不在名称中拼接箭头字符。
- [ ] 保留原 API、权限、字典、分页、确认提示和表单校验。
- [ ] 统计数字来自真实接口；无接口时显示空状态，不写固定演示数据。
- [ ] 动画只增强状态变化，不参与业务判断，不阻塞保存和路由跳转。
- [ ] 支持 `prefers-reduced-motion`，减少动画时页面仍可正常使用。

## 浏览器验收

- [ ] 新增、编辑、查看、删除、查询和重置均通过真实接口验证。
- [ ] 权限不足时菜单和按钮按既有权限系统正确隐藏或禁用。
- [ ] 1440px 宽度下无横向异常、遮挡或跳动。
- [ ] 1024px 宽度下文字不截断，按钮、表格和抽屉不重叠。
- [ ] 空数据、加载、错误、禁用和审核状态均有明确反馈。
- [ ] 浅色模式视觉统一；深色模式至少保证结构不崩坏。
- [ ] 控制台无本模块新增错误。
