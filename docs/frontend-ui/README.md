# FirstSun 前端 UI 开发资料

本目录是药店管理端 V2 现代化界面的统一入口，供 A-F 成员和辅助开发 AI 使用。

## 阅读顺序

1. `V2现代化UI风格规范-初版.md`：了解设计令牌、布局、组件、图标和动效规则。
2. `前端界面统一规范.md`：了解查询区、表格、表单、权限和响应式要求。
3. `demos/pharmacy-modern-ui-v2-motion-demo.html`：查看目标视觉和交互效果。
4. `页面迁移与验收清单.md`：开发前确认边界，开发后逐项验收。
5. `ai-prompts/V2现代化UI升级AI执行提示词.md`：交给 AI 时作为统一任务模板。

## 使用边界

- 演示页面只表达视觉、信息架构和交互方向，不是可直接复制进 Vue 的业务实现。
- 正式页面必须继续使用现有 Vue 3、Element Plus、动态路由、权限、字典和真实 API。
- 不得把演示数据、固定菜单、固定统计值或手写权限判断带入业务代码。
- 公共样式、系统外壳和 `components/Pharmacy` 由 A 统一维护；其他成员只修改自己负责的业务模块。

## 团队落地顺序

1. A 建立公共设计令牌、SVG 图标映射和公共组件。
2. A 先完成药品分类和药品档案两个标准页面。
3. 真实接口与 1440/1024 宽度验收通过后，将公共基础合并到 `main`。
4. B-F 同步 `main`，每人先完成一个代表页面并提交截图评审。
5. 代表页面通过后，再批量迁移同模块其他页面。

## 演示页操作

直接打开 `demos/pharmacy-modern-ui-v2-motion-demo.html` 即可。左侧主导航默认保持紧凑，悬停展开完整名称；点击 Logo 可固定展开或收起。二级菜单可切换药品、分类、条码、门店和员工页面。
