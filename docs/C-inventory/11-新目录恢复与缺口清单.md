## 本轮补齐的查询能力

- 仓库页增加“台账”入口，在同一个代表页面内打开批次库存、货位库存和库存流水三个查询页签；新增“健康”入口，提供效期预警和三账核对；未增加全局路由、菜单或公共字典。
- 批次查询及货位库存查询新增质量状态、效期起止筛选；批次查询支持按货位存在关系过滤，使用 EXISTS 避免同批多明细导致分页重复。
- 流水查询新增仓库、流水类型、来源业务、起始时间与截止时间筛选。流水类型和来源标签使用现有 SQL 基线值，不引入尚未批准的移位枚举。
- 新增 `/batch/get`、`/location/get`、`/flow/get` 详情接口，按登录员工门店及租户取数，缺失或越界统一 NOT_FOUND。
- 从批次行打开 FEFO 预览表单，选择需求数量与本次模拟日期策略；结果明确显示时间、不占库存。相同货位存在不同批次时使用批次+货位复合行键。
- 查询失败清空旧结果；关闭、切换页签、重复查询用请求序号防止旧响应覆盖。日期倒置前端提示、后端同样拒绝。
- 仓库行内保留“台账/编辑”，查看货位和新增货位收入“更多”，避免过宽操作列。
- 效期预警基于现有 `ph_inv_expiry_alert`：按日幂等刷新 30/60/90 天级别，支持查询和一次性处理记录；不改变库存数量或销售放行规则。
- 三账核对在同一 `REPEATABLE_READ` 只读事务中比较批次总量、货位汇总（含货位归属异常）、流水净额、有效锁和期初流水基线，返回逐批次异常标记；不会自动修账。

## 查询契约增量

继续沿用 `/admin-api` 前缀、CommonResult 和 07 中的 query 权限。

| 接口 | 新增筛选/含义 |
| --- | --- |
| GET `/pharmacy/inventory/batch/page` | locationId、qualityStatus 0..2、expiryFrom/expiryTo（YYYY-MM-DD，双端包含） |
| GET `/pharmacy/inventory/batch/location-stock` | qualityStatus、expiryFrom/expiryTo |
| GET `/pharmacy/inventory/flow/page` | warehouseId、flowType、bizType、flowId、flowFrom/flowBefore（ISO 日期时间，包含起点、不包含截止点） |
| GET `/pharmacy/inventory/batch/get?id=...` | 正数 id，批次 query 权限 |
| GET `/pharmacy/inventory/location/get?id=...` | 正数 id，货位 query 权限 |
| GET `/pharmacy/inventory/flow/get?id=...` | 正数 id，流水 query 权限 |

效期起点晚于终点、流水起点不早于截止点均返回参数错误。筛选不含成本权限扩展。流水按仓库过滤时通过历史批次和仓库归属定位，不排除已停用/软删除的批次仓库；硬缺失归属无法判定仓库，只有不传 warehouseId 的门店流水查询可保留此类记录。
