## 接口

沿用 `/admin-api` 管理端前缀及 CommonResult，成功 data 为数据库生成的 ID；客户端路径不重复添加前缀。

### POST /pharmacy/inventory/warehouse/create

权限：`pharmacy:inventory-warehouse:create`。

```json
{"whCode":"C01","whName":"常温仓","tempZone":0}
```

- whCode：非空白，最长 16；whName：非空白，最长 64。
- tempZone：必填整数 0 常温、1 阴凉、2 冷藏、3 冷冻。
- 固定本人员工门店，status=1，is_default=0；不会自动将首仓设为默认仓。
- `uk_wh_code(tenant_id,store_id,wh_code)` 为最终并发唯一约束。编码按现有数据库排序规则裁决；不以 Java 字符串比较代替数据库。已删除资料仍占用唯一键，不恢复或覆写。

### POST /pharmacy/inventory/location/create

权限：`pharmacy:inventory-location:create`。

```json
{"warehouseId":123,"locationCode":"A-01-01","locationType":0,"maxCapacity":1000}
```

- warehouseId：必填正数；locationCode：非空白，最长 32。
- locationType：必填整数 0 常规、1 处方药区、2 特管柜、3 拆零区、4 近效期区；未创造待上架类型。
- maxCapacity：可省略或 null，表示不限制；0 表示零容量；范围 0..4294967295，按 INT UNSIGNED 使用 Long。表单保留 null 与 0 的差异。
- 同一事务先按 tenant/store/id/deleted 获取所属仓库 `FOR UPDATE` 行锁，再检查 status=1，最后插入启用货位。
- 不存在、已删除、他店或他租户仓库统一 NOT_FOUND；停用或非法状态拒绝，不进行 INSERT。
- `uk_location(warehouse_id,location_code)` 为最终唯一约束，含已删除资料。

### 失败与事务

- Controller 进行请求验证和独立权限校验，Service 也声明请求验证；数据范围在执行任何 C Mapper 前解析。
- creator/updater 来自已通过范围验证的登录用户 ID。
- 新增方法声明 `@Transactional(rollbackFor=Exception.class)`。唯一冲突立即转为框架 400 业务异常并向外抛出；失败事务内不重查、重试或返回旧记录作为成功。
- INSERT 必须影响一行并返回正数主键，否则抛错回滚。没有捕获异常后吞掉失败。
- 网络超时仍可能发生“服务端已提交但客户端未知”；页面保留失败提示，需先核对资料再重试。同编码唯一约束防止重复资料，但不等于库存操作级幂等，也不会重放原结果。
- 当前 C 仓库锁约定不能代替其他写入者遵守同一约定；跨模块锁顺序、门店停用生命周期仍需负责人确认。

1. 使用绑定在职员工、拥有 query/create 权限的账号；记录 tenant/store/user。准备另一门店和停用仓库。所有数据仅在明确归自己的独立测试库创建。
2. 新增普通仓库，核对服务端门店/租户/审计字段、status=1、is_default=0；确认接口 ID 与查询和页面一致。
3. 两个连接同时创建相同仓库编码；应一成功一失败，数据库恰一行。测试大小写/尾随空格的现有排序规则、已删除编码，均不产生第二行。不同门店同编码按现有索引可独立存在。
4. 对启用仓库创建货位，检查空容量、0、4294967295；负数、4294967296、非法类型、空白及超长编码拒绝。
5. 他店/他租户/缺失/已删除仓库返回同类 NOT_FOUND；停用仓库拒绝。无登录、无权限、未关联员工、离职、跨租户访问拒绝，表行数不变。
6. 在连接 A 持有该仓库行锁；连接 B 创建货位应等待。A 将仓库停用并提交后，B 应读到停用状态并失败。反向顺序应先创建提交，再允许另一个遵守锁约定的操作继续。
7. 同仓相同货位编码并发创建，仅一行；重复失败不能暴露 SQL 或驱动信息。独立环境中模拟 INSERT 后主键读取异常或事务提交失败，验证失败回滚，不把 Mock 断言当作证明。
8. 仓库页面验证权限隐藏、创建刷新、禁用仓库不能点新增货位；网络失败、重复编码、提交期间重复点击和关闭弹窗。1440/1024 下截图，交 A 评审后扩展后续页面。
