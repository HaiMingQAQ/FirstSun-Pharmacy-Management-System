## 本次 C-08 行为

- 仅允许同仓、当前登录员工门店内的启用仓库和货位。
- 先按 bizNo + bizLineId 检查完整重放，再锁定并移动；部分或冲突流水拒绝。
- 冻结量不可移位；按货位最终净变化检查容量。
- 批次的 qty_total、qty_avail、qty_frozen、qty_sold 不变；每行写源出、目标入两条流水（flow_type=60、biz_type=8）。
- 事务内任一步失败即回滚。
